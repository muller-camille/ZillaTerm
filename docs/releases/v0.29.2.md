**Sessions PSM Windows : les disques de ce poste sont partagés par défaut**, pour copier des fichiers entre le poste et la session.

## Nouveau en 0.29.2

- Nouvelle option, cochée par défaut : Paramètres › CyberArk › **« Partager les disques de ce poste avec les sessions PSM Windows »**. Les disques du poste apparaissent dans la session (Explorateur › Ce PC) ; les programmes de la session peuvent alors les lire et y écrire.
- **Dans un onglet de ZillaTerm** : tous les disques du poste, même si le PVWA n'en demande aucun, reconnexions comprises.
- **Dans la Connexion Bureau à distance** : `drivestoredirect:s:*` est ajouté au fichier du PVWA s'il n'est pas signé. Un fichier signé est donné tel quel (la Connexion Bureau à distance vérifie sa signature, qu'un changement invaliderait) : les disques sont alors ceux demandés par le PVWA.
- Le serveur PSM garde le dernier mot : s'il refuse la redirection des disques, rien n'est partagé.
- Option décochée : comme avant, les disques ne sont partagés que si le PVWA le demande. Elle se diffuse à l'équipe par le **fichier d'environnement** et figure dans le journal de débogage.
