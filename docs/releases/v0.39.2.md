**Client Bureau à distance embarqué mis à jour vers FreeRDP 3.32.2 : version de sécurité, et fin de la boucle d'erreurs « Error code not found: 87 » sur les disques partagés.**

## Nouveau en 0.39.2

### Bureau à distance

- **FreeRDP 3.32.2** pour les sessions PSM affichées dans un onglet et les connexions directes : release `wfreerdp-3.32.2-1` du fork, avec les mêmes correctifs génériques qu'avant (branche `patches-3.32.2`), reportés sans changement.
- **Disques du poste partagés** : FreeRDP 3.32.1 signalait au serveur chaque fermeture de fichier comme un échec dès qu'une erreur Windows était survenue avant sur ce disque (il renvoyait la dernière erreur, même après une fermeture réussie). Le journal de débogage se remplissait alors de `drive_map_windows_err: Error code not found: 87`, en boucle sur un fil par disque partagé. Corrigé dans FreeRDP 3.32.2 : une fermeture réussie est signalée comme telle.

## Sécurité

- FreeRDP 3.32.2 est une version de sécurité : 45 avis publiés par le projet FreeRDP, et un code durci contre les messages d'un serveur ou d'un client malveillant (passerelle, presse-papiers, cartes à puce, codecs d'image, images).
- Le client est vérifié comme les précédents : somme SHA-256 figée et attestation de provenance de GitHub. OpenSSL reste en 3.5.9, dernière version de la branche 3.5.

## Compatibilité

- Rien ne change dans les réglages ni dans la façon d'ouvrir les sessions. Le certificat épinglé du serveur reste vérifié avant tout le reste (`/cert:deny` et empreinte).
